# 回合结束选牌顺序修复

版本：1.0.0　|　已发布

选牌尚未完整结束时，后续回合钩子提前修改炸弹层数或格挡，联机校验可能不同。

## 出现什么问题

- 选牌尚未完整结束时，后续回合钩子提前修改炸弹层数或格挡，联机校验可能不同。

## 什么时候可能遇到

- 酒狐规划专家等回合结束选牌与其他回合结算同时触发。

## 涉及哪些模组

问题类型：其他／尚待分类

## 适用版本

- 配置 known-0.111.0-build：游戏 0.111.0；STS2_WineFox 1.2.18

版本号仅帮助阅读，安装前仍要核对文件。未知版本停止安装，不凭相似名称强行适配。

## 修了什么

- BeforeSideTurnEnd 只等暂停信号便继续枚举后续钩子；现在逐项等待钩子任务及其 GameAction.CompletionTask，再进入下一项，并保留三个原有阶段。
- 运行时按内嵌基线校验依赖；应用失败撤销本补丁已注册的 hooks。

玩法影响：调整全局回合结束钩子的完成顺序；选牌界面依次出现，后续结算延后。

涉及文件：

- TurnEndOrderFix/TurnEndOrderFix.dll：独立修复程序集，含兼容基线。
- TurnEndOrderFix/TurnEndOrderFix.json：游戏 MOD 加载清单。
